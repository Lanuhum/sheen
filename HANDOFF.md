## Что уже работает (проверено)

- **Пайплайн**: bpy → бинарные буферы → `libsheen_c_api` (CUDA) → PNG.
  Нативный модуль `sheen.so` + ctypes-фолбэк на ту же библиотеку.
- **RenderEngine `SHEEN`**: F12, Render Animation, Output/Color Management.
  View Transform принудительно `Raw` — ядро отдаёт готовые sRGB-цвета.
- **Панели Blender для SHEEN**: Light (тип, цвет, мощность, радиус),
  Material, Camera, Output. Панели Cycles/EEVEE исключены.
  Свойства аддона: `Sheen Light` (Light in media, Light Beam, Gobo),
  `Sheen Medium` (Scatter, Extinction, Steps), `Sheen Material` (Reflect).
- **Мост**: материалы по слотам (а не по индексу 0), Principled
  (Base Color, Roughness, Specular, Transmission, IOR, Emission Color/Strength),
  Viewport color как фолбэк;
  нормали `corner_normals` в мир; UV в треугольниках; Image-текстуры из Base Color.
- **Видимые источники (emission)**: `Material.emission_color·emission`
  прибавляется к цвету поверхности — лампа светится сама и видна в отражении.
  Берётся из Principled; CLI `emit <mat> r g b strength`; демо
  `scenes/emission_demo.sheen`.
- **Свет**: SUN (угловой размер → мягкие тени), POINT, SPOT (конус, blend),
  AREA (односторонняя). Затухание `P/(4πd²)`, мягкая тень по `shadow_soft_size`,
  флаг «свет взаимодействует со средой».
- **Поток света у спота**: аддитивный конус, 6 шагов, теневой луч на каждый
  шаг (геометрия внутри конуса вырезает тёмные полосы; стекло прозрачно).
  `Light Beam`, 0 — выключен, тогда ветка не выполняется вообще.
  640×480, 2 спота: +0.65 мс; 1080p: +2.4 мс.
- **Среда**: бокс-контейнер с `sheen_media`, марш с теневыми лучами,
  `sigma_s/sigma_t/samples`, джиттер шагов (убирает ступеньки), ослабление поверхности.
- **Отражение глубины 1** (`Material.reflect`), включая марш среды по отражённому лучу.
- **Преломление** (`transmission`, `ior`), до 3 граней, полное внутреннее отражение;
  стекло прозрачно для теневых лучей. Инверсия линзы проверена.
- **CSG**: union сливает перекрывающиеся интервалы (был разрыв на стыке стоек);
  `se_csg` — примитив только для дерева (стены с проёмами).
- **Текстуры**: одна albedo-карта на материал (`texture_id`, Image Texture на
  Base Color), одна карта свойств (`mask_id`: R — transmission, G — IOR−1,
  B — roughness) и карта нормалей (`normal_id` + `normal_strength`,
  Normal Map из нод). Цепочка мипов строится на хосте, LOD — по footprint
  пикселя, тангенты для нормалей — из UV треугольника (у аналитики —
  произвольный базис). Кубы имеют UV по граням; у plane/sphere/lathe UV условные.
  Демо с жилами: `scenes/granite.sheen`, текстуры в `scenes/textures/`.
- **Прочее**: sRGB при записи, AA из слайдера (1..64), Resolution %,
  пути-каталоги создаются, gobo на прожекторе (текстура по конусу).

   C-API до рендера, свойства — в панели Render Properties («Каустика»);
   в отладке C-API эмитит 50 000 фотонов и строит карту из 12 172. Осталось
   демо со стеклом в конусе прожектора и замеры из Blender (быстрый тест
   с точечным светом дал нулевую разницу — каустика вне кадра или редкая).
   Статус — в `ROADMAP.md`, раздел «Каустика: план и шаг 1».
2. **Gobo: перспективная проекция на плоскость**. Сейчас UV привязан к углу
   конуса, поэтому на наклонных поверхностях паттерн тянется.
3. **Среда**: многократное рассеяние; площадные источники в среде считаются
   по центру, а не по площади.
4. **Текстуры**: mip-фильтрация, вторая текстура на материал, Mapping/UV-transform.

## Правила проекта (не нарушать)

- Всё берётся из свойств Blender. Никаких скрытых дефолтов: нет источников —
  нет света; неизвестный тип лампы — пропуск с сообщением, а не превращение в Sun.
- Скорость важна: новая фича не должна молча замедлять базовый путь;
  выключенная фича обязана стоить ноль (ветка отсекается по нулю).
- Одна истина в памяти: без файлов-прокладок и парсеров в пути рендера.
  CLI (`scene_render` + `.sheen`) — только стенд.
- `ROADMAP.md` — живой план: на каждую фичу добавлять раздел с замерами
  и честными ограничениями.
